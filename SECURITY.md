# Reporting a security issue

Report a suspected vulnerability in this tool privately to the repository maintainer. When GitHub private vulnerability reporting is enabled, use **Security → Report a vulnerability**. If that option is unavailable and no private contact is listed, open a general request for a private reporting channel without including sensitive details.

Include the tool version, OS, Python version, and a minimal synthetic example with the expected and observed behavior. Remove real filenames, private keys, passphrases, and research data. Coordinate disclosure with the maintainer before publishing reproduction details. Ordinary file differences detected by this tool belong with the dataset owner.
